## Context

Team project to design and develop an application for managing music
festivals: budgeting, concert scheduling, event logistics and artist
management. It required an in-depth analysis of the functional and
non-functional requirements, as well as an assessment of constraints and
risks.

## Goals

- Allow a festival to be created and fully managed.
- Manage stand location bookings and ticket types.
- Simulate revenue and model stock based on the tickets sold.
- Manage artist contracts and schedule their performances.

## Implementation

### Phase 1: analysis and design

We gathered requirements from the target users (festival organizers, stand
managers), then separated functional from non-functional requirements. We
formalized the interactions with use case diagrams, each described in detail,
before defining the software architecture in UML: class, sequence and object
diagrams.

### Phase 2: development

Implementation of the main features, then unit and functional tests to check
compliance with the specifications. Change tracking and collaboration went
through Git. The application was deployed on a test server for real-world
trials, followed by adjustments based on user feedback.

## Results

The application covers the management cycle of a festival, from budgeting to
scheduling. Above all, the project showed how much planning and coordination
matter in a team: designing upfront in UML is what allowed us to split the
development without stepping on each other's toes.
